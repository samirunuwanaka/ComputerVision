Q4: Vibrance Enhancement in HSV Space

where $x \in [0, 255]$, $a \in [0, 1]$, and $\sigma = 70$.

  • Display original image, vibrance image, and transformation plot.

Q7: Sobel Filtering & Separable Kernels

Image: q2.jpeg (Einstein)

Implement Sobel filtering using 3 techniques:

  1. OpenCV built-in cv.filter2D.
  2. Custom manual 2D convolution.
  3. Kernel separability property:
    [[1, 0, -1], [2, 0, -2], [1, 0, -1]] = [1, 2, 1]^T * [1, 0, -1]

Compare execution times and numerical consistency across all three methods.
