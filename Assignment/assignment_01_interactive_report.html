Question 1: Piecewise Linear Intensity Transformation

Piecewise linear intensity transformations map input pixel intensities $x \in [0, 255]$ to output intensities $y \in [0, 255]$. The function `intensity_transform(im, breakpoints)` constructs a 256-element Look-Up Table (LUT) via piecewise interpolation.

$$ y = T(x) = y_i + \frac{y_{i+1} - y_i}{x_{i+1} - x_i} (x - x_i), \qquad x \in [x_i, x_{i+1}] $$

Question 3: Gamma Correction in $L^*a^*b^*$ Color Space

Gamma correction is applied strictly to the $L^*$ plane in $L^*a^*b^*$ space to modify luminance without color shift:

$$ L_{\text{out}} = 255 \times \left(\frac{L_{\text{in}}}{255}\right)^\gamma $$

Question 4: Vibrance Enhancement in HSV Color Space

Vibrance boosts muted saturation values while avoiding clipping of already vibrant pixels:

$$ f(x) = \min\left(x + a \times 128 e^{-\frac{(x-128)^2}{2\sigma^2}}, 255\right), \qquad \sigma = 70 $$

Question 5: Custom Histogram Equalization

Custom histogram equalization transforms intensity values to yield a uniform Probability Density Function:

$$ p(r_k) = \frac{n_k}{MN}, \qquad T(r_k) = \sum_{j=0}^k p(r_j), \qquad s_k = \text{round}\left(255 \cdot T(r_k)\right) $$
